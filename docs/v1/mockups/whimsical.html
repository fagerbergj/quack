What changed in pi-durable 1.4

Passed 6 of 6 checksv3 · 11 sources · Researcher v3 · Oct 29

Assumptions. Compared against 1.2.0, the version Collie's SDK was last tested on. Only changes visible in the public API and README count.

Short answer. 1.4 makes recovery more predictable and storage easier to share. Three changes matter for quack: SQLite tables can be namespaced with a prefixS1, a duplicate request id now returns the original submission even after a restartS1S4, and code mode journals each script's results so a resumed script never repeats a finished callS2.

Storage

The SQLite adapters accept { prefix: "pi_" }, which renders prefixed table and index names into every statementS1. Changing the prefix later does not migrate dataS1.

Recovery

Tasks that crash their process are counted and parked after restartLimit restarts, five by defaultS1. A parked task shows in the task graph with reason restart_limit and can be retried by idS1.
