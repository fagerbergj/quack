# Quack v1 design

The rewrite's requirements and design, in the order they are signed off. No code is written until all of them are.

1. **Requirements:** [PRD](prd.md) (why and what), [SRS](srs.md) (core requirements), and one short document per extension in [extensions/](extensions/). All of them trace to [decisions.md](decisions.md), the log of settled answers.
2. **Architecture:** an RFC with diagrams for core and each extension, built on [cloud-agent-layers.svg](cloud-agent-layers.svg). Not started.
3. **UI mockups** of every screen, following the design-frontend skill. Not started.
